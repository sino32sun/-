# 项目罗盘

简洁的中文项目管理软件，支持本地离线运行。

- 多项目管理，任务增删改，负责人、阶段、开始/结束日期、完成进度、备注。
- 项目与阶段进度、完成状态、延期提醒、任务搜索和状态筛选。
- 按任务日期生成甘特图，点击任务条编辑计划。
- 思维导图按“项目 → 阶段 → 任务”自动生成，与任务清单同步；当前不支持自由绘图。
- 浏览器本地存储、JSON 备份/恢复，无账户、无远程服务。

## 开发

需要 Node.js 20.19+ 或 22.12+（当前已验证 Node.js 24）。

```sh
npm ci
npm run dev
npm test
npm run build
```

生产版本通过 `npm run preview` 验证。浏览器端集成检查：先运行
`npm run preview -- --port 4173`，再执行 `node tests/browser.mjs`。
该检查使用 `/usr/bin/chromium`，其他平台需调整测试文件中的 executablePath。

## 本地离线使用

`releases/项目罗盘-离线版.zip` 是已构建的程序，不需要 Node.js 或 npm 安装。
电脑只需预先安装 Python 3，将压缩包完整解压后：

- Windows：双击 `start.bat`。
- macOS / Linux：在解压目录执行 `sh start.sh`。

脚本启动仅监听本机的静态服务，并打开本机浏览器。运行期间无需互联网。
保持启动窗口打开；Ctrl+C 停止服务。请不要直接双击 HTML 文件。
离线包使用固定的 `127.0.0.1:8765` 地址，确保本地数据位置一致。
生产版本也提供 Service Worker 缓存，浏览器加载完成后可断网刷新。

数据保存在当前浏览器 localStorage 中。清除网站数据、使用隐私窗口、
改变地址或浏览器可能使原有数据不可见，请定期导出 JSON 备份。
导入会覆盖全部现有项目，操作前会要求确认。当前不支持多人同步。

## 重新打包

```sh
npm run build
python3 scripts/package_offline.py
```

## 验证

5 项模型测试覆盖日期范围、任务状态、汇总进度、甘特日期与备份校验。
浏览器检查覆盖创建任务、跨视图进度同步、刷新持久化、断网编辑与移动端布局。
