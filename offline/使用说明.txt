项目罗盘 · 本地离线版

1. 将整个压缩包解压到电脑上，保留 app 文件夹。
2. 电脑需要预先安装 Python 3。运行时无需联网，不需要安装任何 Python 依赖。
3. Windows 双击 start.bat；macOS / Linux 在本目录执行 sh start.sh。
4. 浏览器会打开本机地址 http://127.0.0.1:8765 。保持启动窗口运行。
5. 使用完毕，在启动窗口按 Ctrl+C 关闭服务。

不要直接双击 app/index.html；必须使用启动脚本。
全部资源随包提供，没有在线字体、接口、登录或外部服务依赖。

功能：多个项目；任务增删改；负责人、阶段、计划日期、进度和备注；
状态与延期跟踪；甘特图；按项目/阶段/任务组织的思维导图；JSON 备份和恢复。
首次运行提供可删除的示例项目。通过“我的项目”旁的 + 创建自己的项目。
思维导图是任务的工作结构视图，不支持自由绘图或任意层级节点。

数据存储在当前浏览器的本机存储中，不保存在压缩包或 Python 服务端。
请固定使用相同浏览器与地址（127.0.0.1:8765），不要使用隐私浏览模式。
清除网站数据、更换浏览器或更换地址会导致数据不可见。务必定期“导出备份”。
导入 JSON 会替换现有全部项目，操作前请先导出备份。
当前为单机个人版，多人共享和跨设备同步尚未提供。
